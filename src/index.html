1 · Login Chrome

Pilih marketplace → Buka Chrome → login/verifikasi secara normal. Biarkan Chrome tetap terbuka saat proses berjalan.

Masukkan link toko dan jumlah produk. Tombol START otomatis berubah menjadi STOP selama engine berjalan.
